## Status definitions

| Status | Requires (evidence in this log) |
|---|---|
| **NOT PRACTISED** | No session entry. |
| **PRACTISED** | ≥ 1 logged session: timed, done without notes, with a self-score and a written gap list. |
| **MASTERED** | **All** of: ≥ 3 sessions on at least 2 different days spanning ≥ 14 days; the last 2 scored ≥ 4/5 overall; at least one session was on an *unseen variation* of the question (or evaluated by another person); no unresolved gap in "must-fix" items; you can deliver the core answer in half the original time. |

Rules: never upgrade on the strength of "I read it" or "I understand it"; downgrade to PRACTISED if a later session scores ≤ 2/5; peer/mentor feedback outranks self-score when they disagree; record the date of each status change.

## Scoring rubric

Score each 1–5, then record the overall (not necessarily the average — judge holistically).

| Dimension | 1 | 3 | 5 |
|---|---|---|---|
| Requirements & scoping | Jumped in | Asked basics | Clarified scale, consistency, non-goals; stated assumptions |
| Structure & communication | Rambling | Mostly ordered | Signposted, time-managed, checked in |
| Technical correctness | Major errors | Mostly right | Correct, with edge cases |
| Trade-offs | None | Mentioned | Compared alternatives with reasons and numbers |
| Failure & consistency thinking | Happy path only | Some failures | Crash points, commit points, recovery named |
| Depth on follow-ups | Stuck | Partial | Fluent with examples |
